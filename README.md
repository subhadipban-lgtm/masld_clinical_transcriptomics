# MASLD-CDSS: Curated Database Browser

This is a hypothesis‑generation tool that provides curated drug–gene interactions from CTD, DrugBank, DrugCentral and DGIdb for user‑supplied gene lists. It does not perform any prediction or ranking; it simply looks up known interactions.

**Disclaimer:** For research and hypothesis generation only. No therapeutic recommendations are made.
